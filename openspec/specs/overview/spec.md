## Purpose

OpenSpec is an offline emulation server and game content reconstruction suite for Final Fantasy
Brave Exvius. It rebuilds and serves game data, supports local gameplay through a synthetic server
and Android client adaptations, and preserves access to events and modes that would otherwise depend
on the original online service.
