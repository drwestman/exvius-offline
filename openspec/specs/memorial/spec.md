# Memorial Specification

> Generated by openlore v1.2.0 on 2026-11-07 15:24

## Purpose

Intercepts game runtime activity to swap English plate images, adjust dialog content and layout, and
trigger limit burst assets or dialogs.

> `source/memorial/frida_script.js`
